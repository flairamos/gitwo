命令行

gitwo serve [-home <dir>]                 启动平台（Web + Git HTTP/SSH + 站点托管）
gitwo deploy -repo <归属/仓库> [-branch …] [-sha …]
                                          手动触发部署（可指定历史提交回滚）
gitwo serve-static -addr :3000 -dir <dir> [-spa]
                                          独立静态文件服务器（工具）
gitwo version                             查看版本

可选配置（data/server.yaml）

listen: :9527            # Web / Git / 站点 / API 端口
ssh_listen: ":2222"      # SSH Git 服务；设为 "" 禁用
workers: 2               # 全局并发部署数
max_queued_per_repo: 5   # 每仓库排队上限
verify_index: true       # 前端部署后校验 index.html
port_min: 20000          # 自动分配端口范围
port_max: 23999
notify_webhook: ""       # 部署结束回调 URL（JSON）
timeouts: {git: 5m, build: 10m, deploy: 5m, stop: 15s, start_wait: 2s, stall: 20s}

未知字段会被拒绝启动（防拼写错误），修改后重启生效。
