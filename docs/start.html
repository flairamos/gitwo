快速开始

只需要一台装有 Go 1.22+ 的机器（运行期只需要系统 git）。

本地构建与启动

Windows（PowerShell / cmd）

go build -o gitwo.exe .
.\gitwo.exe serve
# 数据目录 = 二进制所在目录
.\gitwo.exe serve -home D:\gitwo-data

Linux / macOS

go build -o gitwo .
./gitwo serve
./gitwo serve -home /tmp/dp
nohup ./gitwo serve -home ~/dp-smoke &

部署到服务器（systemd）

GOOS=linux GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o gitwo-linux-amd64 .
sudo GITWO_BIN=gitwo-linux-amd64 ./scripts/install.sh
sudo systemctl enable --now gitwo
# 防火墙只需放行 9527（Web/Git/站点/API）与 2222（SSH Git）

第一条流水线

# 1. Web UI 新建仓库 demo
# 2. 克隆并放入 index.html 与 deploy.yaml（examples/demo-static 是现成例子）
git clone http://admin:admin@服务器:9527/git/admin/demo.git && cd demo
git add -A && git commit -m "first" && git push origin main
# 3. 打开 /pipelines 看实时构建；访问 /sites/admin_demo/ 查看部署结果

默认账户 admin / admin，首次登录后请立即修改密码。SSH 主机密钥首次启动自动生成于 data/ssh/。
